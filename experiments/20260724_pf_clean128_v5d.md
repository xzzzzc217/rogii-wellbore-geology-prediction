## Sole behavioral repair

V5d preserves every v5 clean parameter and changes only RNG ownership:

1. derive a stable positive 31-bit seed from
   `SHA256(namespace, well_id, branch)`;
2. pass distinct stage/split/ANCC-or-Z seeds from both scoring `build_well`
   functions;
3. call `np.random.seed(seed)` before the first random draw in every
   `_pf_ancc` and `_pf_z` execution;
4. move `_resamp` random draws into the seeded parent in their original order,
   making `_resamp` a deterministic helper;
5. replace random JIT beam warm-up arrays with deterministic linspace inputs.

The branch namespace covers:

- `sp45_train_ancc`, `sp45_train_z`;
- `sp45_test_ancc`, `sp45_test_z`;
- `learned_train_ancc`, `learned_train_z`;
- `learned_test_ancc`, `learned_test_z`.

Python `hash()` is prohibited because its result is process-randomized.
SHA-256 seed derivation depends only on well and branch, so joblib scheduling
and traversal order cannot change a well's seed.
