# Experiment ledger

Create one Markdown or JSON record per experiment. At minimum record:

- immutable experiment ID and timestamp;
- code commit;
- data/input versions;
- hypothesis and material change from the parent experiment;
- validation split definition;
- overall and per-well RMSE;
- runtime and hardware;
- artifact paths;
- public score, if submitted;
- conclusion and next action.

Do not overwrite prior results. Failed and negative experiments are evidence.
