# ROGII 数据审计与验证建议

审计日期：2026-07-23
数据目录：`data/competition`
范围：只读扫描 773 口训练井与 3 口测试井；轻量基线直接使用训练文件中已经存在的 `TVT_input` 缺失后缀作为验证区，没有随机造掩码、没有训练复杂模型。

## 结论先行

1. **存在确定的同井、同行标签重叠。** 测试井只有 `000d7d20`、`00bbac68`、`00e12e8b` 三口，它们全部也在训练目录中。对每口井，训练与测试水平井文件行数相同，`MD/X/Y/Z/GR/TVT_input` 六列逐值完全一致（含 NaN 位置）；训练文件还额外包含完整 `TVT`。
2. `sample_submission.csv` 的 **14,151 行全部能按 `well_id + row_index` 在训练文件中找到非空真实 TVT**：分别为 3,836、6,014、4,301 行。因此，若比赛规则允许使用官方数据包内的重叠数据，直接按提交 ID 查训练 `TVT` 是首要完整性基线；在本地对这些行的 RMSE 按构造为 0。
3. 不能用普通随机行切分评估泛化。训练集中每口井的真实预测区都是连续后缀，773/773 口井均非空且均为单一后缀；必须整井分组，并把相同 typewell 指纹和空间近邻井放进同一折。
4. 在 3,783,989 个原生掩码行上，最简单的“最后已知 TVT 常数外推”RMSE 为 **15.9099**，明显优于单位 Z 外推（107.4948）、末端 128 点 MD 线性外推（119.4214）和末端 128 点 Z 线性外推（215.1999）。长距离线性外推会灾难性发散，不能作为无保护主模型。

> 风险提示：同井标签重叠来自已下载的官方比赛文件，但在真正提交前仍应阅读比赛的 data-use / leakage 条款，并先用一个最小提交验证提交 ID、行号和评分口径。不要把此泄漏路径与泛化模型 OOF 混在同一个分数里。

## TVT 平滑性与特征关系

对每口训练井分别计算相关系数，再对井取分位数，避免把井间绝对坐标差异误当成井内关系：

| 特征 vs TVT | P10 | 中位 | P90 | 解释 |
|---|---:|---:|---:|---|
| `MD` | 0.4198 | 0.5246 | 0.6068 | 只有中等单调关系 |
| `Z` | -0.9797 | -0.9235 | -0.7324 | 强相关，但单位斜率并不成立 |
| `GR` | -0.5785 | -0.2295 | 0.0803 | 原始点值关系弱且井间方向不稳定 |
| `X` | -0.5577 | -0.3903 | 0.5432 | 方位相关符号随井改变 |
| `Y` | -0.5353 | 0.4172 | 0.5520 | 方位相关符号随井改变 |

TVT 一阶绝对差（全井抽样）中位数仅 0.02，P90 0.62，P95 0.92，P99 1.08，P99.9 1.58；极值 15.61。目标整体非常平滑，但局部转向会让长距离线性外推累积巨大误差。模型应预测相对最后已知点的低频残差，并显式惩罚不合理的一阶/二阶跳变。

## GR 缺失与 typewell

- 训练水平井 GR 缺失 1,507,972 / 5,092,255，缺失率 **29.6130%**。
- 测试水平井 GR 缺失 3,784 / 19,221，缺失率 **19.6868%**。
- 测试预测区内 GR 缺失率差异很大：
  - `000d7d20`：1,816 / 3,836，**47.3410%**；
  - `00bbac68`：832 / 6,014，**13.8344%**；
  - `00e12e8b`：418 / 4,301，**9.7187%**。
- 训练 typewell 的 `(TVT,GR)` 序列共有 752 个唯一指纹；13 个重复组涉及 34 口井，最大重复组有 10 口井。最大组为：
  `02e7fe5a,10b89021,3417285d,6ae68655,7993a768,bc4381e2,ecdab904,f021b650,f49fdea3,f88ddb26`。
- 三口测试井的 typewell `(TVT,GR)` 都与同井训练 typewell 逐值完全一致。
- 用真实 TVT 将 typewell GR 线性插值到水平井位置后，井内 GR 相关系数中位 0.7550（P10 0.6091，P90 0.8632），对应每井 GR RMSE 中位 11.9294。说明 typewell 对齐是强信号，但不能只靠单点 GR，尤其是 `000d7d20` 的大面积缺失区。
- `Geology` 在训练 typewell 中缺失率 33.4052%；必须有显式缺失类别，不能把空值当作数值 0 或前向填充跨地层。

typewell 重复指纹是验证泄漏源：同一指纹组若跨折，模型可能记住整条参考曲线。分折时必须先按指纹合并为 group。

## 推荐的泄漏安全 OOF

建议保留两个完全分开的验证轨道。

### Track A：泛化 OOF（模型选择主轨）

1. 一口井的所有行只能出现在一个 fold；绝不随机切行。
2. 为每口井计算 typewell `(TVT,GR)` 指纹，重复指纹 34 口井先合并为不可拆 group。
3. 用井口或首个有效点的 `(X,Y)` 做空间聚类/网格分组；空间近邻组不可跨折。若有 pad/field 元数据，优先用真实 pad/field group。
4. 在 group 层做 5 折，按以下井级量贪心平衡：预测行数、预测占比、目标范围、GR 缺失率、typewell 对齐质量。评分同时报告：
   - 全部预测行的 row-weighted RMSE；
   - 每井 RMSE 的中位/P90/最大值；
   - 每折 RMSE 和折间标准差。
5. 只使用测试可得字段：`MD,X,Y,Z,GR,TVT_input`、typewell `TVT,GR` 及其泄漏安全派生特征。

推荐的首版 fold 分层桶：

- 预测占比：`<65%`、`65–70%`、`70–77.5%`、`77.5–80%`、`>=80%`；
- GR 缺失率：`0`、`(0,10%]`、`(10%,30%]`、`(30%,50%]`、`>50%`；
- TVT 范围：按训练井四分位数（约 588.57、758.22、856.51）；
- typewell 指纹重复 / 唯一；
- 空间 cluster。

### Track B：比赛重叠完整性轨（只验证数据映射）

- 用 sample ID 最后一个下划线拆成 `well_id` 和 0-based `row_index`。
- 从同井训练水平井取该行 `TVT`，并断言：
  - 14,151 个 ID 唯一；
  - 井号仅为三口测试井；
  - 行号都在范围内且正好落在 `TVT_input` 缺失后缀；
  - 训练 `TVT` 全部非空；
  - 训练/测试六个共享列在对应全井逐值相等。
- Track B 的 0 RMSE 只说明映射正确，**不能**用于模型选择或宣称泛化能力。

## 最有价值的 5 个模型诊断

1. **按井尾部距离分桶的 RMSE**：把每个预测后缀归一化成 10 个位置桶，看误差是否随外推距离累积；这是线性外推爆炸最直接的报警器。
2. **灾难井仪表盘**：每井 RMSE、最大绝对误差、首个预测点跳变、末端漂移，同时报告 P50/P90/max；优化目标不能只看全局 RMSE。
3. **GR 缺失 × typewell 对齐分层**：按 GR 缺失桶和 typewell 插值相关性桶交叉报告。`000d7d20` 的 47.34% 预测区 GR 缺失应单列。
4. **形状约束诊断**：预测与真值的一阶差/二阶差分位数、预测区边界连续性。训练真值一阶绝对差 P99 约 1.08，超大跳变应被裁剪或正则化。
5. **泄漏哨兵**：分别报告“同井/同 typewell 可见”和“同井及同指纹完全隔离”的 OOF；若前者显著更好，说明模型在记忆井或参考曲线。

## 可落地的建模顺序

1. 先实现并测试 Track B 的精确映射，但提交前确认规则。
2. 将最后值常数（RMSE 15.9099）设为不可回退的 fallback。
3. 泛化模型预测 `TVT - last_known_TVT`，而不是绝对 TVT；输入归一化后的后缀位置、相对 `MD/X/Y/Z`、GR 缺失掩码和 typewell 对齐特征。
4. 优先尝试序列/对齐特征：typewell GR 在候选 TVT 上的相似度、窗口互相关、DTW/平滑位移、局部 GR 统计；对缺失 GR 单独走几何与先验分支。
5. 对模型输出做最后值基线残差收缩与范围保护；任何候选必须同时改善 row-weighted RMSE、P90 井 RMSE和灾难井最大值。

## 本轮限制

- 没有训练复杂机器学习模型，也没有做超参数搜索。
- 没有汇总 typewell 总行数；其余本文数字均来自本轮只读扫描。
- TVT 一阶差分位数使用每口井最多约 1,000 个等距抽样差分，适合诊断，不应当作精确总体分布。
- 空间聚类尚未实际拟合；这里给出的是避免坐标邻近泄漏的可执行分折设计。
